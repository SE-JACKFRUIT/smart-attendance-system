## Sprint 1 script (about 60 s)
1. (0-10 s) Open the app. First run goes to `/setup`. Create the Admin and log in.
2. (10-30 s) Enroll a student. Show the 100-sample capture with head-pose prompts. Student appears in the list.
3. (30-50 s) Take Attendance, show your face, press `q`. Review screen lists only the recognised student.
4. (50-60 s) Save. Show GitHub: closed stories and green CI.

Say: "Sprint 1 covers setup and login, role protection, enrollment, model training, live recognition and CI."

## Sprint 2 script (about 120 s)
1. (0-20 s) Quick recap: login, enroll.
2. (20-45 s) Add more samples (total 200).
3. (45-80 s) Take attendance, untick one student on the review screen, save. Point out `marked_by` (auto vs faculty username). Save again to show no duplicate.
4. (80-100 s) Dashboard percentages, then Export CSV and open it.
5. (100-115 s) Log in as the student (roll / roll): only their own record.
6. (115-120 s) Show `docs/DEVIATIONS.md` and the PR history.

Say: "Sprint 2 covers review and overrides, the audit trail, analytics, CSV export and student view. Deviations are documented."
